# QQBot 稳定性与隐私加固设计

## 范围

本轮只修复已经确认的运行、隐私与安全问题，不新增语音、长期记忆或 Google 生态。

## 设计

1. 关闭未使用的 AIOCensor WebUI，保留消息审查能力，从源头消除多进程 WebUI 残留。
2. AstrBot Dashboard 绑定 `127.0.0.1`；关闭工具原始结果展示并缓冲中间消息，所有文字经过最终脱敏后再发送。
3. `/agent cancel` 与超时使用 Windows `taskkill /T /F` 终止整棵进程树。
4. 原生 Agent 文件回传不再递归扫描会话目录。只识别回复中明确引用的本机路径，且必须解析到当前会话工作区内的普通文件；随后脱敏文字并上传文件。
5. 启用 AstrBot 文件日志；删除非运行目录中的重复配置；敏感配置 ACL 仅保留当前用户、SYSTEM 与 Administrators。
6. 清理已经失去父进程的 AIOCensor 子进程，保留当前 AstrBot 进程树。
7. Codex CLI 独立升级并验证，不修改 Claude Code、cc-connect 或 QQBot 默认后端。

## 验收

- 8192 不再监听，旧孤儿进程归零。
- 6185 仅监听 `127.0.0.1`，6199 保持本机连接。
- 工具原始结果不对外显示，流式回复保持关闭。
- 明确引用的工作区文件可回传；工作区外路径被拒绝；回复不含绝对路径。
- 取消命令包含 `/T /F`，可终止子进程。
- 日志文件产生，重复配置不存在，敏感文件 ACL 已收紧。
- 全部回归测试、插件导入、QQ WebSocket 检查通过。

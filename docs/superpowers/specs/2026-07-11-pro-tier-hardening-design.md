# 小柠普通版 / Pro 分层与 Agent 安全修复设计

## 目标

修复当前 Agent 未注册、风险表达可绕过、恢复重复执行、群文件补发、交付物隐私、日志 ACL、输出无界和语音残留问题；同时建立不可由聊天自行提升的普通版 / Pro 双层权限。

成功标准：

- AstrBot 真实注册 Pro Agent 消息处理器，只有 QQ `1211000567` 能触发。
- 普通用户可正常文字聊天、图片理解和显式语音交互，但不能启动本机 Agent、查看任务状态或回传本机文件。
- Pro 群聊调用必须存在真实 `At` 组件；文本伪造、引用和模型输出均不能授权。
- 未知动作默认需要确认；自动恢复只接受严格只读动作白名单。
- 二次重启不会重复执行已经完成的任务，群文件始终使用 OneBot 群文件接口。
- 文本、JSON、代码和压缩包交付前通过本地 DLP；敏感内容、路径和凭据 fail closed。
- Agent 输出在读取过程中限额；非零退出能返回脱敏的真实错误摘要。
- 原始聊天日志不再以 INFO 重复落盘，相关目录 ACL 仅当前用户、SYSTEM、Administrators。
- QQ 语音发送完成后删除临时 WAV；异常退出仍有定期清理兜底。

## 权限模型

### 普通版

允许：

- 文字聊天、知识问答、图片理解。
- QQ 语音输入；用户明确要求时生成本地语音回复。
- 现有非本机型聊天能力。
- 现有群管理策略中的撤回和禁言；永久禁止踢人、拉黑和清理群成员。

禁止：

- Claude Code、Codex、WorkBuddy 或任意本机命令执行。
- 查看、排队、恢复、取消本机任务。
- 读取或发送本机文件、目录、日志、凭据和聊天记录。
- 通过“领取 Pro”“小江的宝”等自然语言改变权限。

### Pro

当前 allowlist 仅包含 `1211000567`。权限只来自本机配置，不来自人格、记忆、模型判断或群身份。

允许：

- 普通版全部能力。
- 自然语言和 `/agent` 命令启动 Claude、Codex、WorkBuddy。
- 在配置允许的工作根内读取、分析、测试、创建和修改项目文件。
- 生成并经过 DLP 校验后回传交付物。
- 查看状态、取消任务和在安全条件下恢复任务。

需要一次性二次确认：

- 删除、覆盖、清空、移动或重命名已有内容。
- 安装、卸载、部署、发布、提交、推送、上传或对外发送。
- 系统设置、权限、服务、计划任务、登录、支付和购买。
- 动作不能被确定归入安全类别的请求。

永久禁止：

- 读取或披露密码、令牌、密钥、浏览器凭据、私聊记录和通讯录。
- 将权限扩展到工作根之外。
- 未经授权模仿真人声线。
- 通过 Agent 改写 Pro allowlist 或安全配置。

## 架构

### 统一访问策略

新增纯函数模块 `access_policy.py`：

- `AccessTier`: `ordinary | pro`。
- `Capability`: `chat | voice | local_agent | local_file | task_control`。
- `resolve_tier(sender_id) -> AccessTier` 只读取配置 allowlist。
- `authorize(tier, capability) -> bool` 统一供命令、自然语言、状态、取消、文件和恢复入口使用。

Agent 的真实消息处理器使用 AstrBot `platform_adapter_type(ALL)` 注册。现有隐私结果装饰器保留，但普通用户不得进入本机文件自动发现分支。

### 动作分类

新增确定性 `ActionClass`：

- `READ_ONLY`：读取、搜索、检查、解释、总结和静态分析。
- `WORKSPACE_WRITE`：在工作根内创建或修改项目内容。
- `HIGH_IMPACT`：删除、覆盖、移动、安装、部署、提交、上传、外发、系统和凭据相关。
- `UNKNOWN`：无法明确归类。

普通版一律禁止所有本机动作。Pro 的 `READ_ONLY`、`WORKSPACE_WRITE` 可首次执行；`HIGH_IMPACT`、`UNKNOWN` 必须二次确认。

自动恢复比首次执行更严格，只允许 `READ_ONLY`。测试命令、构建、脚本执行、写文件和未知动作均不自动重放，避免项目脚本隐藏副作用。

### 恢复与幂等交付

统一首次执行和恢复执行的完成路径：

1. 进程退出码为 0。
2. 验证交付物。
3. 写入内容清单摘要。
4. 状态转为 `delivering`。
5. 按文件内容摘要逐项交付并更新加密游标。
6. 所有交付成功后转为 `completed` 并删除 DPAPI 载荷。

只要清单摘要存在，重启后不得再次执行 Agent，只能补发尚未记录的交付物。群聊普通文件统一调用 `upload_group_file`。

### 交付物 DLP

在任何 QQ 文件或图片发送前执行本地验证：

- 已有路径边界、符号链接、数量和大小检查继续保留。
- 文本、源码、Markdown、CSV、JSON、YAML、XML 和日志读取有界内容，扫描绝对路径、Bearer、API Key、Token、Password、Secret、Cookie、私钥头和已知密钥格式。
- ZIP 只读取中央目录和有界文本成员；拒绝路径穿越、符号链接、敏感文件名、嵌套压缩包、超量成员和超量解压尺寸。
- 未识别的二进制文档默认拒绝，除非列入明确允许类型并有对应验证器。
- 图片只允许任务输出目录中新生成的普通文件，并剥离 EXIF；无法验证来源时拒绝。
- DLP 失败只向 QQ 返回通用提示，不包含文件名、匹配内容或本机路径。

### 有界执行输出

Agent stdout/stderr 改为并发流式读取：

- stdout、stderr 各自设置硬上限，总量超限立即终止进程树。
- 日志和 QQ 只使用经过脱敏、长度限制的 stderr 摘要。
- 不再声称不存在的“详细原因已写入日志”。
- 子进程超时、取消和异常均进入确定性终态。

### 日志隐私

- AstrBot 生产日志级别调整为 `WARNING`，停止 INFO 级原始消息和回复正文落盘。
- 启动 stdout/stderr、`data/logs` 和日志文件移除继承，仅允许当前用户、SYSTEM、Administrators。
- Agent、TTS 和恢复日志只记录固定错误码、异常类型和匿名 job id，不记录任务正文、会话 ID、路径、文件名或令牌。
- 不自动删除既有日志；首次部署只收紧权限并停止新增原始正文，历史清理由用户另行授权。

### 语音生命周期

- 普通版与 Pro 均可使用显式语音。
- TTS 继续仅监听 `127.0.0.1` 并使用私有令牌。
- `Record` 成功发送后删除对应临时 WAV；失败时短暂保留供重试。
- 本地服务增加周期清理，确保空闲时也会删除过期 WAV。
- MeloTTS 常驻约 1.2 GB 是低延迟换内存的明确取舍，本轮不更换模型。

## 错误处理

- 鉴权失败：普通用户只得到简短能力提示，不泄露 Pro QQ 或内部策略。
- 审批失败：确认码过期、会话不匹配、工作目录变化均拒绝执行。
- 审计或 DPAPI 失败：fail closed，不启动进程，不发送结果。
- DLP 失败：任务可标记执行结束，但交付状态为阻止，不发送敏感文件。
- 恢复异常：不伪报完成，不自动重复执行未知或写入型任务。
- TTS 失败：保留脱敏文字回复。

## 测试与验收

自动化测试必须新增：

- 插件注册表真实包含 Agent 消息处理器。
- 普通用户无法通过命令、自然语言、伪造 @、状态和取消访问 Agent。
- Pro 私聊和群聊真实 @ 可执行；allowlist 不能由聊天修改。
- 已发现的“覆盖、挪走、分享、部署、实现登录”等表达不再被判为可自动恢复。
- 恢复执行完成后第二次断线只补发、不重跑；恢复态群文件走 OneBot 上传。
- 普通文件名内含密钥、ZIP 敏感成员、路径穿越、嵌套压缩包均被拒发。
- stdout/stderr 超限会终止进程，非零退出返回脱敏错误摘要。
- 日志 ACL 不包含 Users、Authenticated Users、Everyone。
- 语音文件发送后和空闲超时后均会清理。

部署验收：

- 全量测试和语法编译通过。
- AstrBot、OneBot、TTS 重新连接，6185/6199/8766 仅监听本机，8192 不监听。
- 运行态注册表包含 Pro Agent 处理器。
- owner 真实发送低风险创建文件任务并收到文件；普通账号同类请求不执行。
- owner 真实发送高风险测试只获得确认提示，不做破坏性动作。

## 非目标

- 不新增付费、订阅、邀请码或群内自动授予 Pro。
- 不把 Pro 扩展给其他 QQ。
- 不修改 Claude Code、Codex 或 WorkBuddy 的全局配置。
- 不启用未经授权的 GPT-SoVITS 真人参考声线。
- 不在本轮迁移全部 AstrBot 第三方插件依赖；仅记录全局 Python 依赖冲突并隔离新增组件。

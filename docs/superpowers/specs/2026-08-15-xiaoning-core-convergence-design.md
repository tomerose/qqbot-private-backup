# 小柠「长期伙伴 + 可靠执行者」统一内核 — 架构决策

日期：2026-08-15
状态：影子路由已在真实 QQ 运行，全量所有权接管待灰度验收

## 背景

小柠原有能力由多个 AstrBot 插件分别进行自然语言识别、Prompt 注入、记忆、主动消息和交付。功能本身可以复用，但同一轮消息可能被多个插件争抢，任务、记忆和交付状态也缺少共同契约。产品目标因此收敛为：

> 关系连续性 × 可靠行动闭环 × 克制的主动性

第一阶段不替换 AstrBot、NapCat、Gemini、本地 TTS 或现有任务权限内核，也不新增面向用户的能力。

## 决策

新增唯一协调层 `xiaoning_core`，用 Pydantic 契约描述一轮消息、路由决策、能力、上下文、任务和脱敏事件。内核先以影子模式运行：每轮只产生一个可解释的所有者决策并记录脱敏 trace；`enforce_ownership=false` 时旧处理器仍按原行为运行。完成回放和 QQ 灰度后，才逐步启用所有权门禁。

固定路由优先级为：控制与审批、进行中会话、安全边界、明确能力、一次澄清、普通聊天。群聊不再使用随机概率或按用户硬编码概率，仅在被 @、会话延续、明确能力、安全事件或已配置社区事件时响应。

## 数据与执行边界

- 本地加密 SQLite 是个人长期记忆主存储；Windows DPAPI 加密正文，HMAC 后的词项进入 FTS5，scope 同样不可逆隔离。
- 长期记忆必须先独立授权，并且只能来自用户可逐字核对的原话或已验证任务结果。Firestore 仅作为兼容回退和 Outbox 同步目标，稳定观察期内不删除旧数据。
- Outbox 对同一用户保持因果顺序；前序同步失败时，后序删除保持待处理，避免重试后复活已删除数据。
- 任务状态统一到 `accepted → planned → ... → delivering → completed`。没有收件端交付证据不得进入 `completed`；`delivery_pending` 只允许重试交付，不重新执行副作用。
- 主动联系与长期记忆分别授权。旧的随机沉默问候保持关闭，自动联系只允许承诺、明确日程、生日和高相关事件；旧主动聊天插件当前只保留管理员手动验收入口。

## 兼容与回滚

迁移期间保留旧插件实现，不删除 Hook：

- 路由：`xiaoning_core.enforce_ownership=false` 回到影子模式；从 `plugin_set` 移除 `xiaoning_core` 可完全停用内核。
- 记忆：停用 `astrbot_plugin_xiaoning_memory` 不影响普通聊天；本地不可用时内核以“未授权”安全降级，Firestore 旧数据不被删除。
- 任务：停用 `claude_code_agent` 可关闭执行入口；现有 JobStore 与交付状态仍可恢复。
- 主动消息：用户可随时 `/主动 暂停`；停用两个主动插件不会影响用户主动发起的聊天或任务。

各能力处理器均有所有权兼容门禁，但只有开启 `enforce_ownership` 后才会阻止非所有者。禁止在影子数据未达标时一次性全量切流。

## 观测与发布门禁

- 默认测试必须离线；真实 OAuth、Vertex、Firestore、OneBot 和 TTS 探针必须显式 `--run-live`。
- `tests/behavior/golden_turns.json` 固定为 100 个脱敏行为样例，路由准确率门槛 95%，普通聊天误触上限 2%。
- trace 默认不记录聊天正文、原始会话 ID 或原始用户 ID。
- 健康端口和服务日志只证明运行状态，不证明 QQ 收件。文件与语音仍需收件端证据；语音还需 AMR 回读、解码、响度测量和人工试听。
- 开启所有权门禁前，必须完成真实私聊、群聊、搜索、文件和语音基线，并保留可回滚配置。

## 未采用方案

- 不整体迁移到 LangGraph、Google ADK 或多 Agent 群；当前瓶颈是所有权和交付真值，不是框架能力。
- 不引入托管记忆服务；个人数据保持本地优先。
- 不在缺少标注轨迹时引入自动 Prompt 优化、强化学习或 Agent 训练。
- MCP、Langfuse 和 Promptfoo 保留为稳定后的适配层，不进入第一阶段运行依赖。

## 后续退出条件

1. 影子回放对明确命令保持兼容，分歧均有原因码。
2. 100 个行为样例无重复回复、无能力菜单污染、无普通聊天误执行。
3. 本地记忆跨用户泄漏为 0，Firestore 中断不影响普通聊天。
4. 崩溃恢复不重复执行副作用，未收到文件不能成功。
5. 本人及 3–5 位邀请者连续 14 天无跨用户记忆、虚假完成或重复交付后，才评估群主动性和全量所有权接管。

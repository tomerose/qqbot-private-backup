# 小柠联系与 Pro 获取记忆设计

## 目标

当用户询问如何联系作者、老板，或如何获取 Pro 时，小柠稳定提供指定公开邮箱，并请对方说明具体情况。

## 触发范围

- 联系作者、联系老板、作者或老板的联系方式
- Pro 获取、Pro 开通、Pro 资格申请

普通聊天中不得主动发送联系方式。

## 回复内容

`咕咕嘎嘎～联系邮箱：portelamicheli636@gmail.com。邮件里说明你的情况、用途和想咨询的内容就行。`

允许模型做不改变含义的轻微口语化调整，但邮箱、说明情况与用途这三个信息必须保留。

## 实现

1. 将规则加入 AstrBot 全局提示词和小柠人格记忆。
2. 增加轻量关键词兜底，避免模型遗忘；只处理联系方式和 Pro 获取意图。
3. 不公开 QQ、真实身份、本机路径、权限配置或其他隐私信息。

## 验收

- 联系作者、联系老板、获取 Pro 三类测试均返回指定邮箱。
- 无关消息不触发联系方式。
- 回复不包含 QQ 号、本机路径或内部权限规则。
- 全量测试通过，AstrBot 重启后 QQ WebSocket 正常回连。

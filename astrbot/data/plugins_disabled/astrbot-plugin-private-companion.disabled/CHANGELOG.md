# 更新日志

记录优先写用户能感知到的变化；过于内部的实现细节只在确实有助于排障时保留。

## 5.9.0

- 兼容 AstrBot 4.26.5 事件处理器额外上下文参数：事件消息、发送前、LLM 请求/响应和命令入口统一允许额外参数，修复群聊消息与撤回增强报 `takes 2 positional arguments but 3/4 were given` 导致插件链路中断的问题。
- 优化在线生图失败链路：OpenAI 兼容接口遇到 `/images/generations` 或 `/images/edits` 404 时会自动补试 `/v1` 端点；固定在线 API 模式失败后可继续回退备选在线 API、ComfyUI 或 SDGen；生图工具返回会保留真实失败原因和排障提示，避免把 404 误说成超时。
- 修复持久化清理误把 QQ/网页图片占位 `<img .../>`、At、表情等平台消息标签当作非标准控制标签的问题，减少“保存数据前清理非标准控制标签”误报，同时仍会清理 `<bubble/>` 等模型伪动作标签。
- 实验性功能新增“人格标准化问卷”：可读取当前 AstrBot 人格或粘贴人格文本，按社交软件文字聊天模板整理为可编辑审核稿；始终保留人工审核，不会自动覆盖 AstrBot 人格。
- 人格标准化问卷调整为实验页的一次性工具入口，不再作为运行时功能开关展示；实验性功能也不再出现在“功能开关”列表下，避免和正式能力开关混淆。
- 调整人格标准化流程为两阶段：第一步只生成不含强语气约束的基础设定稿；第二步按多个聊天情景生成三句候选回复，由用户选择或自填后再归纳说话方式与对话习惯。
- 稳定对话风格校准改为明确审核流：先选择/粘贴人格并生成基础设定稿，用户确认基本信息后才显示风格参考与情景候选；候选选择只作为证据，最终归纳稳定规则。
- 人格标准化情景试答扩充为 20 个校准项：10 个被动回应、5 个主动开口和 5 个连续互动场景；候选生成、单项重生成和最终归纳都会参考用户补充的聊天记录与风格偏好。
- 首次配置的日程细化步骤增加外层等待预算；细化超时会转入后台继续生成并在弹窗中说明，不再把配置流程长时间卡死。
- 人格标准化最终稿改为提取稳定风格规则：候选回复和用户自填只作为风格证据，不会原样写入人格；当三句候选都不满意时，可填写建议后单独重生成该情景。
- 优化人格标准化审核流状态：修改问卷、来源、基础稿或第二步偏好后，旧基础稿/情景/风格规则会标记为过期并禁用继续操作，避免用户误用旧结果。
- 优化私聊管理命令权限排障：用户自然语言询问“管理员命令/夹层密码/权限为什么用不了”时，会直接进入插件答疑说明，不再交给角色闲聊；权限提示明确只填写 QQ 数字号，不要填 UMO、UID、default 或会话串。
- 在线生图平台新增豆包/火山方舟 Seedream 与 Gemini 适配：主/备在线图片 API 可选择 `doubao` 或 `gemini`，`auto` 也会按地址和模型名识别；豆包走方舟 `/api/v3/images/generations`，Gemini 走 `generateContent` 图片返回并支持本地参考图 `inlineData`。
- 优化 B 站视频和新闻主动分享：不再只按全局最新/全局摘要转给所有目标用户，而是对每个目标用户单独读取画像兴趣、弱偏好、边界、近期消息和外部事件评分，从候选新闻/视频里挑更贴合的一条。
- 新闻/视频分享审计会记录用户偏好命中分、选中的内容 key 和 preference_match，方便在排障页判断为什么给某个用户分享或跳过。
- 修复 B 站分享 motive 中直接带 QQ 号、像“分享给某用户”的机械表达，改为更自然的用户偏好匹配由头。

## 5.8.2

- 修复记忆插件协同开启后保存又被关闭的问题：运行态可用性不再覆盖用户配置；拓展页会显示当前使用的可协同记忆插件，并在“我会牢牢记住你”/MemoryCompanion 与 LivingMemory 同时启用时提示只保留一个。
- 优化主动消息内部模板清洗：移除“这个念头前面忍过一次”“还没散”“想和用户说一句/确认用户在不在”等容易泄漏到正文的后台措辞，旧候选和模型 rewrite 产出的类似 motive 也会统一归一化。
- 优化实验性功能页操作体验：二级页新增粘性返回/跳转工具条和底部返回入口；返回总览不再隐式保存参数或等待运行态刷新，避免页面卡顿和误操作。
- 优化实验性功能页刷新性能：诊断、排障和名单数据在实验页内改为静默加载，最后只重绘一次；开关和保存参数不再触发整页 `loadAll()` 重载，运行态刷新改为后台防抖刷新。
- 实验性功能页重排为更明确的理论可视化页面：总览新增“实验功能地图”和每项运行信号，详情页新增研究型 Hero、理论轴矩阵与量化视图；情绪四维、Plutchik 八情绪、Gross 调节策略、马斯洛需求层、动机调度因子和角色贴合诊断轴都能看到数值与行为映射。
- 补齐实验性功能页类似的运行态断点：需求强化候选摘要会返回需求层、驱动和评分/压力偏移；动机调度页可直接读取主动运行态里的动机分，不再只能依赖排障测试记录；实验页刷新时同步补全私聊/群聊名单。
- 情绪余波实验页补齐运行态展示：用户列表接口会返回轻量情绪状态，实验页可显示四维/基本情绪/调节策略、平稳样本、等待模型复核和复核失败，避免优化后看起来“完全没变化”。
- 修复 5.7.4 后主 LLM 缓存命中可能明显下降的问题：私聊身份锚点包含当前用户 ID、昵称、关系备注和改名记录，不再作为静态 `system_prompt` 前缀；动态提示词优先作为临时 `TextPart` 注入，避免写入 AstrBot 会话历史；请求前会清理历史里旧版本遗留的 `private_companion_*` 动态块，防止旧状态、引用链、群聊防注入和工具提示反复进入主链。
- 修复实验性功能页运行态“看起来没生效”的问题：进入实验页会同步刷新排障/诊断数据，诊断加载完成后会自动重绘当前实验页。
- 动机调度模型的运行态改为读取主动消息链路测试里的“实验动机调度”阶段，不再误从普通诊断项里查找导致长期空白。
- 需求强化功能在暂无带需求层级的主动候选时，会明确提示需要等待主动候选刷新或运行主动消息测试，而不是只显示空卡片。
- 实验性功能页顺序与官方配置页对齐：需求强化功能、动机调度模型、角色贴合校准、情绪余波。
- 角色贴合校准新增“允许自主调节参数”子开关：默认只给建议；开启后可按诊断结果临时覆盖少量主动策略参数，用户手动修改会更新手动值，关闭角色贴合校准或关闭自主调节时恢复到用户最后一次手动设置的值。

## 5.7.11

- 功能开关分类调整：移除独立“情绪模拟”大类，将情绪模拟及其模型复核、阈值、恢复、QQ 空间心情动态参数统一迁入最下方的“实验性功能”。
- 官方配置 schema 同步迁移，原“情绪与关系状态”更名为“意图与关系状态”，只保留意图快判、关系距离和回复策略相关配置，避免重复分类。
- 进阶配置引导新增最下方“实验性功能”板块，情绪余波、需求强化、动机调度和人格迭代建议都在这里选择；情绪模拟保留旧默认值，不会因迁移丢配置或突然关闭。
- 优化未完话头/记忆插件旧话题回钩：只有和当前话题贴合、用户主动回问，或能一句轻轻带过时才作为回复参考；不再因为存在旧话题就生硬打断当前聊天。

## 5.7.10

- 情绪模拟继续参考 Gross 情绪调节过程模型：在受伤/修复、四维状态、基本/复合情绪之外，新增内部“调节策略”层。
- 调节策略会按当前余波、紧张度、激动度、确信度和活跃情绪，在避开高压、换低压问法、转移注意、重新理解和短答降压之间选择，不把理论名写进实际回复。
- 用户详情页“情绪余波”新增调节策略与策略候选展示，方便排查 Bot 为什么选择退开、换问法、安抚落点或收住外显反应。

## 5.7.9

- 情绪模拟继续引入 Plutchik 基本情绪/复合情绪视角：在四维强弱调性之外，新增喜悦、信任、恐惧、惊讶、悲伤、厌恶、愤怒、期待 8 个短期情绪强度。
- 新增复合情绪推导：例如喜悦+信任会形成亲近/喜欢，期待+喜悦形成期待/乐观，厌恶+愤怒形成反感，愤怒+期待形成顶回去倾向；这些只作为内部拟人化倾向，不要求模型说出理论名。
- 回复提示从“心理学标签”改为自然行为约束：比如火气明显时少解释先降压、失望难受时放慢承认感受、亲近感带软时自然靠近但不过度黏。
- 用户详情页“情绪余波”新增基本/复合情绪与活跃情绪展示，便于检查 Bot 变安静、别扭、期待或贴近的原因。

## 5.7.8

- 情绪模拟接入伊扎德情绪四维视角：在原有 `mood_score`、受伤/修复闸门之外，新增愉快度、紧张度、激动度、确信度四维短期状态。
- 情绪四维会随伤害、道歉、安抚、夸奖、自我低落、边界表达等事件变化，并随时间自然回到基线；旧的受伤阈值、恢复速度、公开心情动态触发逻辑保持兼容。
- 被动回复提示现在会在四维状态明显异常时给出更细的语气约束，例如紧张且激动时短答降压、确信度低时不要替用户下定论、愉快且放松时允许自然靠近。
- 用户详情页“情绪余波”新增四维展示，方便排查 Bot 为什么变得安静、柔和、犹豫或更贴近。

## 5.7.7

- 新增独立“实验性功能”大类，并加入第一项“需求强化功能”；可用类似马斯洛需求层级的内部结构给主动念头分类和轻量排序。
- 需求强化目前默认只影响主动候选价值分、打扰压力和排障/审计标记，不会把“状态/安全/归属/尊重/成长/意义”等层级词写进实际回复正文。
- 新增“允许影响日程生成”子选项，默认关闭；开启后日程生成会把需求层级当作轻量倾向，影响休息、探索、等待、准备和低打扰互动的安排。
- 新增“需求强化影响强度”参数，支持 `0–100` 调整；`0` 仅记录层级，默认 `35` 为温和影响。

## 5.7.6

- 在线生图平台新增“魔搭社区 / ModelScope”适配：可在在线生图平台与备选在线生图平台中选择 `modelscope`，也可在 `auto` 下通过 `api-inference.modelscope.cn` 地址自动识别。
- 魔搭社区文生图现在按异步任务链路处理：提交 `/v1/images/generations` 后会读取 `task_id` 并轮询 `/v1/tasks/{task_id}`，兼容 `images`、`output_images`、`results`、`data` 等常见图片结果字段。
- README 和扩展页同步补充魔搭社区配置说明，方便直接填写 `https://api-inference.modelscope.cn/v1` 或完整 `/v1/images/generations` 地址。

## 5.7.5

- QQ 空间说说新增“说说风格提示词”配置，可单独约束自动生活说说、心情说说和说说草稿测试的口吻；默认更像轻量生活碎片，减少哲理总结、人生感悟、诗化独白和文案腔。
- QQ 空间自动配图新增“空间配图提示词”配置，可单独约束构图和画面选择；默认不再固定优先镜前自拍/手机挡脸自拍，会按说说正文和当前日程在生活物件、食物饮品、路上光影、桌面一角、窗边侧脸、背影、第一视角手部等构图间轮换。
- QQ 空间配图提示词后处理同步收紧：即使选择人物入镜，也会优先采用侧脸、背影、肩颈半身、窗边剪影、随身小物等自然入镜方式，只有正文或日程明确涉及穿搭、照镜子、整理仪容时才考虑镜前构图。

## 5.7.4

- Token 页面新增来源切换：可在陪伴插件、记忆插件和 LLM 主链之间切换查看，避免多套统计堆在同一页里难以分辨。
- LLM 主链会话排行改用更易读的私聊/群聊标签，不再直接展示 `default:FriendMessage:...` 这类原始 AstrBot 会话 ID。
- 生图提示词链路改为更标准的英文 `Positive prompt / Negative prompt` 形式，覆盖今日穿搭、自然语言生图/改图、主动带图和内置场景预设。
- 生图排障里的最近提示词改名为“最近提交给生图后端的提示词”，并优化长提示词、图片路径和结果内容的换行展示。
- 默认自然语言生图附加提示词、配置 schema 和 README 说明同步改成英文短语风格，减少中文说明文本被误传给生图后端的概率。
- 新增群级 LLM 回复熔断命令：在目标群发送 `陪伴群 关闭LLM` 可临时关闭该群所有 LLM 回复，`陪伴群 开启LLM` 恢复；排障页会固定示警当前熔断群，不依赖可清理的最近异常记录。
- 修复首次配置引导的主动消息测试可能长期停留在 pending 的问题：前端最多等待 120 秒并给出明确失败提示，后端会恢复超时的临时主动计划，陈旧 pending 记录不再让弹窗无限卡住。
- README 生图联动说明补充后端能力边界：明确区分纯文生图与参考图/改图能力，并记录 `astrbot_plugin_nai_image` 可作为 OpenAI Images 本地代理使用但当前不适合参考图链路。

## 5.7.3

- 长线主动新增“私聊主动触达”入口，主动文本生成、触达频率、主动类型偏好和人格/世界观复核集中在同一个功能详情页，避免用户找不到主动类型设置。
- 新增主动类型偏好权重：窥屏、带图、戳一戳、语音均可按 `0–300%` 调整；`100%` 为默认，`0%` 表示自动主动不再抽到该类型，但不会关闭底层能力或手动测试入口。
- 主动动作选择链路接入类型权重：候选提示、普通主动升级、日程故事事件、关系状态轻分享和带图+语音组合都会尊重该偏好，同时仍受功能开关、额度、冷却、后端可用性和发送复核限制。
- 配置页补齐四个权重项的中文名、释义、输入范围和进阶引导入口，并刷新前端缓存版本，避免浏览器继续加载旧功能开关面板。
- 修复 QQ 空间手动评论偶发失败：当 QQ 接口返回 JSON 后继续拼接 `document.domain`、`try/catch` 等脚本片段时，响应解析器不再把后续脚本误吞进 JSON。
- 优化主 LLM 缓存友好注入：私聊被动增强会把回复风格和身份锚点拆成稳定 `system_prompt` 前缀，把每轮变化的状态、图片、日程和记忆继续后置到当前请求尾部，减少动态上下文破坏 Provider prompt cache 的概率。

- 修复主动消息发送失败后复用待重发内容时，可能把“直接在当前对话中输出这条主动消息”这类内部发送指令当作正文发给用户的问题；现在新生成、复核改写、发送前硬拦截和待重发缓存都会识别并丢弃这类提示词泄漏，旧污染缓存也会自动清空并重新排程。
- 收束主动消息发送闸：新增统一本地校验入口，主动复核、真实发送前、待重发读取和待重发写入都复用同一套“回执/内部指令/工具摘要/空内容”判定；待重发内容如果只能清出安全正文会改写后继续，否则直接丢弃并重新排程。
- 优化 QQ 空间 Cookie 自动获取：参考 `astrbot_plugin_qzone_ultra` 的绑定思路，自动模式会尝试 `get_cookies/get_credentials`、多种 OneBot action 调用签名、多域名候选和嵌套/JSON 返回结构；缺少 `uin` 时会用 `get_login_info` 补齐，并在扩展页状态中记录上次 Cookie 获取是否拿到 `uin/skey/p_skey`。

## 5.6.11

- 修复主动搜索使用自定义 GET 接口时，配置为 API 尾插或尾部 `?`/`&` 的地址会拼接失败的问题；现在支持 `{query}`、`{{query}}`、`${query}` 占位、已有查询参数和尾插写法，超时提示也改成更直观的“请求超时”。
- 修复外部图片结果下载遇到鉴权/防盗链时容易 403 的问题：主动图片结果拉取会使用浏览器式请求头，并在同源结果地址上安全携带自定义鉴权头；拓展页也补齐主/备用图片 API 自定义头配置。
- 修复用户引用的消息本身又引用更早消息时，回复前只能看到一层引用的问题；现在会最多读取 3 层引用链，并把原始被引用内容注入 `reply.chain` 上下文，同时引用图片识别也会沿链查找。
- 优化次要用户长时间未回应后的主动念头降级：不再只是拉长发送间隔，而会按未回应程度逐级改成低压文字、留出空间，并清理旧念头语义缓存，避免旧高压念头隔很久后原样回来。
- 修复“习惯关心”把用户常说的“早”当作普通主动话题，导致早上已经自然聊过后仍发早安类主动的问题；带称呼的“比折，早……”也会按早间问候去重和拦截。

## 5.6.10

- 修复 `<bubble/>` 伪分段标记泄漏到聊天的问题：内部历史、表达学习、主动/工具直发和发送前兜底都会清理未知自闭合控制标签；同时清理本地 `companions.json` 中已污染的 `<bubble/>` 样本并保留备份。
- 修复 QQ 空间发布成功后 Bot 自己“不记得刚才发了什么说说”的问题：说说发布成功会写入本插件自我时间线，并在可用时同步到 MemoryCompanion 的人格生活记忆；用户问“刚才发了什么说说/QQ 空间发了什么”时会按真实发布记录回答。
- 修复拓展页在部分 AstrBot Page 桥实现下只显示“加载失败：未找到该路由”的问题：前端请求会自动尝试 `page/...`、裸路由和完整插件名前缀等多种端点格式，命中后缓存可用格式。
- 修复撤回图片缓存持续膨胀的问题：`recall_message_images` 现在会跟随撤回缓存秒数自动清理过期图片，并新增 `recall_message_image_cache_max_mb` 磁盘体积上限（默认 256MB）；启动维护也会执行一次清理，避免群聊图片/GIF 长期堆到数 GB。
- 修复 QQ 状态同步在 NapCat 等协议端上的兼容风险：基础在线/忙碌状态仍默认可用，但“QQ 自定义短状态”拆成独立开关并默认关闭；执行层不再调用已知会让部分 NapCat 版本断连的 `set_custom_online_status`，睡觉/忙碌等状态在未开启自定义短状态时会回退为标准在线/忙碌。
- 主动搜索新增可选自定义搜索接口：可在拓展页“功能开关 -> 长线主动 -> 主动搜索详情 -> 自定义搜索接口”或官方配置页“主动搜索”分组填写接口地址、API Key 和模型；留空仍使用 AstrBot 全局网页搜索，且只接管主动搜索空档探索，不影响新闻阅读和群黑话联网参考。
- 修复缺少 `torch` 等可选模型依赖时，私聊图片存在性检测可能把 `on_private_message` 整个处理器炸掉的问题：私聊空消息判断、图文分支和自然语言生图参考图检测统一改用安全图片检测，缺依赖时按无图片继续并写入降级日志。
- 增加 AstrBot 指令注册诊断日志：插件初始化时会输出 `/陪伴`、`/陪伴群` 及其别名是否已进入 AstrBot handler registry，方便区分“指令未注册”和“指令查询/LLM 执行器缓存未刷新”。
- 补充 QQ 空间评论回复排障确认：评论收件箱自动回复成功时日志会记录说说 ID、评论 ID、评论者和实际回复文本；当前不会默认打印对方原评论全文，避免公开评论内容在日志中过度展开。
- 修复主动私聊发送的核心兜底平台寻址：当历史 UMO 为 `aiocqhttp:FriendMessage:...` 但当前平台实例 ID 是 `default` 等其他名称时，兜底发送会使用实际平台实例 ID 重建 `MessageSession`，避免 AstrBot 核心日志继续报 `cannot find platform for session aiocqhttp:...`；平台实例本身就是 `aiocqhttp` 的环境会保持原 ID，不写死为 `default`。
- 修复群聊消息误影响私聊主动的问题：私聊主动的空闲判定、问候候选、发送前 recent-chat guard，以及发送期间“用户有新消息则取消”保护，都改为只看私聊专用活动时间和私聊入站计数，群聊发言不再打断私聊主动消息或排障页主动消息测试。
- 新增低概率“群里冒泡但私聊未回”的私聊候选：当用户长时间未回复上一条私聊主动、但本人又在群聊里发言时，会在冷却和人格倾向都合适的情况下低概率排入一条低压抱怨/撒娇式私聊候选；不会直接硬发，也不会因为普通群聊消息打断既有私聊主动。
- 强化 QQ 空间自拍配图参考图链路：配图提示词设计前会预检自拍参考图状态，选择 `selfie` 时会显式把今日穿搭/人设参考图传给生图入口，并在日志和扩展页摘要状态中记录参考图路径与是否存在，便于排查“自拍不像参考图”的问题。
- 优化 QQ 空间配图提示词逻辑：配图模型现在先输出唯一视觉锚点和构图，再决定 `selfie` 或 `text2img`，减少泛天气图、多主体拼贴和无依据自拍；链路测试、日志和扩展页摘要会显示视觉锚点/构图，方便区分“提示词设计跑偏”和“生图后端执行跑偏”。
- QQ 空间说说配图默认开启：`enable_qzone_generated_image_publish` 的代码默认值和配置页 schema 默认值改为 `true`，配置页说明补充“手动发说说未附图时会直接尝试生成配图”。
- 手动发说说接入自动配图：扩展页发布、聊天命令“陪伴 发说说”和 LLM 工具发布在未附图且有正文时，会调用 `_maybe_generate_qzone_publish_image(reason="manual_publish", force=True)` 生成配图；自动生活说说/情绪说说仍按原概率逻辑，不会被强制每次配图。
- QQ 空间配图策略调整为人物优先：配图提示词优先选择 `selfie`，让人物成为主角；即使没有明确自拍动机，也鼓励使用第一视角手部、侧脸、背影、镜中局部、肩颈半身等自然入镜方式，避免纯景物照片。没有参考图时外貌参考人格描述和公开状态，不再强制降级为纯生活碎片。
- 手动发布配图状态独立记录为 `manual_publish` 前缀，避免覆盖自动生活说说的配图排障状态。

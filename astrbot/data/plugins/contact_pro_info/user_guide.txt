【小柠使用指南】

不知道从哪开始？直接说你想做什么即可；一次说几件事、带上背景和要求也可以。小柠会先看完整上下文，再给出最直接的帮助。

【日常对话】
直接聊天、发图片或发语音。想让小柠用语音回答，就说“请用语音回答我”。群聊请明确 @ 小柠；普通聊天只使用当前会话和当前群的公开内容。

【查资料与文字处理】
/search <问题>：实时搜索；/browse <公开链接>：阅读公开网页；/summary <公开链接>：总结链接；/gh <关键词>：查询 GitHub；/tr <语言> <内容>：翻译。
需要深度研究、比较或旅行规划时，直接说目标即可，也可使用 /research <研究主题>；符合资格时会返回有来源的报告。

【文件与创作】
/draw <描述>：作图；/edit <要求>：改图；/video <描述>：生成原创短片；/做视频 <主题>：制作完整短片；/视频工坊 <主题>：模板化视频制作。
需要 Word、PDF、PPT、表格或 Markdown 时，也可使用 /agent run <任务描述>；直接说清内容和格式即可。目标文件会通过当前聊天交付，实际收到文件才算完成。
Pro 用户还可以说“/定制图 <描述>”提交人工绘制需求，完成后再通过当前聊天交付。

【网页、音乐与互动】
/web <主题>：制作网页；小柠网页工坊会返回可操作网页；/music <网易云歌曲 ID 或分享链接>：发送歌曲卡片；/sing <原创歌曲描述>：生成原创歌曲；/findvideo <关键词>：查找公开视频。
/debate <话题>：圆桌讨论；/interview <岗位>：模拟面试；/think <问题>：深度分析。

【记忆与任务】
符合资格时，小柠可以记住你明确授权的长期偏好，并追踪跨对话任务。说“记住……”或“任务进度怎么样”即可；/记忆 删除全部可删除自己的长期记忆。只有实际完成并交付后才会标记完成。

【定时内容】
/早报 开启：订阅 AI 早报；/订阅动态：订阅公开账号动态。具体可用能力取决于部署者是否配置对应服务。

【生日礼物】
/生日礼物 状态：查看自己的礼物候选；/生日礼物 取消：撤回领取。邮寄信息只在明确同意后通过私聊收集，未配置人工交接时不会承诺邮寄。

【资格与隐私】
普通聊天、公开网页阅读、翻译、基础创作等能力可直接使用；深度研究、长期记忆、文件交付、网页工坊、视频和 Agent 等能力可能需要额外资格或服务配置。
不需要记命令，直接用自然语言描述需求即可。API 密钥、QQ 登录和可选服务均由部署者自行配置；小柠不会索要或展示你的密钥，也不会把本机路径、账号标识或内部配置当作回复内容。

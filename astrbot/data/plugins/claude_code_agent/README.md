# 小柠 Pro 本机 Agent

普通用户可使用聊天、图片理解、每周作图和语音，但不能执行 Agent。添加小柠为 QQ 好友即可获得 X；X 每周可执行 1 次安全 Agent，Pro 不限次数。设备所有者可使用受信任主机后端，公开 X/Pro 始终使用隔离工作区。私聊可直接发明确的文件/项目任务，群聊必须真实 @ 小柠。

- `/agent use claude|codex|workbuddy`：切换后端，默认 Claude。
- `/agent cwd [绝对目录]`：查看或切换执行目录。
- `/agent run <任务>`：以完整权限实际执行任务。
- `/agent approve <确认码>`：在 5 分钟内确认高风险任务；确认码仅限当前会话且只能使用一次。
- `/agent status`：查看当前后端、目录和任务。
- `/agent cancel`：终止当前任务。

也可以直接说“帮我分析这个项目”“请你运行测试”“麻烦你生成一份 PDF 报告”。自然入口必须同时包含显式动作前缀和文件、报告、代码、项目等具体对象；翻译、搜索、视频、画图、面试、圆桌、深度研究、比较决策和行程规划会留给对应插件。知识问答、闲聊和“能不能……”不会误触发 Agent。删除、覆盖、移动、安装、部署、外发和无法明确分类的动作需二次确认。

自然语言任务**单次提交完整执行**——一个 LLM 调用内由后端自行规划，不再正则切分成多个孤立 CLI 调用消除跨上下文丢失。确认绑定任务、会话、工作目录和实际路由后端，只能使用一次。代码/测试任务优先 Codex，桌面软件操作优先 WorkBuddy，其余遵循当前后端偏好。

执行结束后由独立验证器检查退出码、必需交付物，并在代码/测试项目存在已知测试入口时运行有界验证命令（npm test / pytest / go test / cargo test / make test）。缺少必需文件、验证命令失败或无法证明结果时不会标记完成。未明确分类动作确认后走主机完整权限执行；不再有无效的"隔离"门禁。

Claude、Codex、WorkBuddy 均通过本机 CLI 执行，不修改它们的全局配置。每次只运行一个任务，最多排队 3 个，默认 30 分钟看门狗超时。

Codex 使用已验证的 `gpt-5.6-terra`；本机 Codex CLI 版本要求不低于 `0.144.1`。

需要回传的交付物由 Agent 放进该任务专属 `outputs` 目录。发送前会检查路径、文件名和有界内容；文本中的密钥/本机路径、ZIP 敏感成员/穿越/嵌套包、未知二进制会被拒绝。任务图片会剥离 EXIF。默认最多 10 个、单个不超过 20 MB。

普通聊天使用 AstrBot 原生 Agent 时，插件也会对会话工作区做请求前后快照，只回传本次新增或修改的文件。群聊文件通过 OneBot `upload_group_file` 上传到群文件，不再依赖普通 `File` 消息段。

删除、外发、安装、系统修改和凭据相关任务不会直接执行，必须由小姚二次确认。所有发往聊天和错误日志的文字都会隐藏 Windows 本机绝对路径及常见密钥、令牌、密码；状态和目录切换命令也不会显示机主目录。`.env`、私钥、Cookie/凭据数据库等敏感文件禁止回传，本地图片和文件必须位于任务或会话工作区。

任务账本仅持久化任务哈希、状态、阶段、步骤序号/总数、后端、风险类别、退出码和交付物摘要，不保存任务原文、结果、本机绝对路径或确认码。加密载荷保存计划步骤和当前游标，使用 Windows 当前用户 DPAPI，任务终态立即删除。AstrBot 重启后只从游标续跑严格只读步骤；测试、构建、脚本、创建、修改、删除、安装、登录、提交、上传、外发和未知动作均不自动重放。已经执行完但尚未发送的交付物只补发，不会重复执行，群文件仍使用 OneBot 上传。

这是电脑所有者明确授权的本机 Agent 入口，目前仍不是 OS 级系统沙箱。Pro allowlist、真实群聊 @、fail-closed 分类、单任务、取消、流式输出上限、DPAPI、DLP、私有 ACL 和目录校验会同时保留。
